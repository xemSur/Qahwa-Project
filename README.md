# نخبة الضيافة – الموقع الإلكتروني

واجهة عربية RTL متجاوبة لمشروع نخبة الضيافة في المدينة المنورة، مبنية باستخدام React 19 وTypeScript وVite.

## التشغيل المحلي

```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج

```bash
npm run build
npm run preview
```

ملفات الإنتاج تظهر داخل `dist/`.

## الحجز عبر واتساب

رقم الحجز مضبوط في `src/App.tsx` داخل المتغير `WHATSAPP` بصيغة دولية دون علامة +: `966547143565`.
